# Use Case Documentation - Кассовая система

Этот каталог содержит документацию вариантов использования (use cases) системы кассы.

## Файлы

### 1. use_case_descriptions.md
Полное текстовое описание всех use cases системы, включая:

- **Актёры системы**: Администратор, Кассир с описанием их прав доступа
- **7 основных use cases**:
  - UC-001: Авторизация в системе
  - UC-002: Управление товарами
  - UC-003: Управление пользователями
  - UC-004: Проведение продажи
  - UC-005: Просмотр и экспорт отчёта о продажах
  - UC-006: Очистка истории продаж
  - UC-007: Выход из системы

Для каждого use case описаны:
- ID и название
- Актёры
- Предусловия и постусловия
- Основной поток выполнения
- Альтернативные потоки (обработка ошибок)

Также включены:
- **Бизнес-правила** (BR-001 - BR-007)
- **Нефункциональные требования** (NFR-001 - NFR-005)

### 2. use_case_diagram.puml
PlantUML диаграмма вариантов использования, визуализирующая:

- Границы системы
- Актёров (Администратор, Кассир)
- 7 основных use cases
- Подчинённые use cases (добавление/удаление товаров, регистрация/удаление пользователей, поиск/корзина/оплата)
- Связи между актёрами и use cases
- Include и Extend связи
- Комментарии к критическим операциям

## Просмотр PlantUML диаграммы

### Вариант 1: Онлайн-редактор PlantUML
1. Откройте [PlantUML Online Editor](https://www.plantuml.com/plantuml/uml/)
2. Скопируйте содержимое файла `use_case_diagram.puml`
3. Вставьте в редактор
4. Диаграмма отобразится автоматически
5. Можно экспортировать в PNG, SVG, PDF

### Вариант 2: VS Code с расширением PlantUML
1. Установите расширение "PlantUML" от jebbs
2. Установите Java (требуется для рендеринга)
3. Откройте файл `use_case_diagram.puml`
4. Нажмите `Alt+D` для предварительного просмотра
5. Или выберите команду "PlantUML: Preview Current Diagram"

### Вариант 3: Локальная установка PlantUML
1. Скачайте plantuml.jar с [официального сайта](https://plantuml.com/download)
2. Установите Java (если ещё не установлена)
3. Запустите команду:
   ```bash
   java -jar plantuml.jar use_case_diagram.puml
   ```
4. Будет создан файл `use_case_diagram.png`

### Вариант 4: Visual Studio Code с PlantUML Server
1. Установите расширение "PlantUML"
2. В настройках VS Code добавьте:
   ```json
   "plantuml.server": "https://www.plantuml.com/plantuml"
   ```
3. Откройте файл `.puml` и используйте предварительный просмотр

## Структура диаграммы

Диаграмма организована в 5 пакетов (модулей):

1. **Аутентификация** (LightBlue)
   - Авторизация в системе
   - Выход из системы

2. **Управление товарами** (LightGreen)
   - Основной UC: Управление товарами
   - Подчинённые: Добавление товара, Удаление товара

3. **Управление пользователями** (LightYellow)
   - Основной UC: Управление пользователями
   - Подчинённые: Регистрация пользователя, Удаление пользователя

4. **Продажи** (LightCyan)
   - Основной UC: Проведение продажи
   - Подчинённые: Поиск товара, Управление корзиной, Оплата

5. **Отчётность** (LightPink)
   - Просмотр и экспорт отчёта о продажах
   - Очистка истории продаж

## Типы связей

- **Ассоциация** (сплошная линия): Актёр может выполнить use case
- **Include** (пунктирная стрелка): Обязательное включение одного UC в другой
- **Extend** (пунктирная стрелка): Условное расширение UC при определённых условиях

## Примечания к критическим операциям

На диаграмме указаны технические детали для важных операций:

- **UC-002 (Управление товарами)**: Использует транзакции SERIALIZABLE
- **UC-004 (Проведение продажи)**: Использует блокировку строк `with_for_update()`
- **UC-005 (Отчёт о продажах)**: Экспорт в CSV с UTF-8 BOM, агрегация по артикулу

## Разграничение прав доступа

### Администратор (полный доступ):
- ✅ Все 7 use cases
- ✅ Управление товарами
- ✅ Управление пользователями
- ✅ Отчётность
- ✅ Проведение продаж

### Кассир (ограниченный доступ):
- ✅ Авторизация/Выход
- ✅ Проведение продаж
- ❌ Управление товарами
- ❌ Управление пользователями
- ❌ Отчётность

## Связь с кодом

Описанные use cases реализованы в следующих файлах:

### Backend:
- `db_actions/user.py` - UC-001, UC-003, UC-007
- `db_actions/products.py` - UC-002, UC-004, UC-005, UC-006
- `endpoints/user.py` - REST API для UC-001, UC-003, UC-007
- `endpoints/products.py` - REST API для UC-002, UC-004, UC-005, UC-006

### Frontend:
- `pages/AuthPage.tsx` - UC-001, UC-007
- `pages/AdminPage.tsx` - UC-002, UC-003, UC-005, UC-006
- `pages/CashierPage.tsx` - UC-004
- `api/functions.ts` - Все API-запросы для всех UC

## Использование документации

Эта документация предназначена для:

1. **Разработчиков**: Понимание требований при реализации функций
2. **Тестировщиков**: Составление тест-кейсов на основе потоков UC
3. **Аналитиков**: Уточнение бизнес-требований
4. **Заказчиков**: Проверка соответствия системы ожиданиям
5. **Новых членов команды**: Быстрое погружение в функциональность системы

## Актуальность

Документация соответствует текущей версии системы с:
- Моделями: User, Product, SoldProduct
- Ролями: admin, cashier
- Транзакционной обработкой: SERIALIZABLE + row-level locking
- Отчётами с агрегацией и CSV-экспортом
